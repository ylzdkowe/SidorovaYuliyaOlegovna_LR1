# MyNotesApp

Учебное WPF-приложение: заметки, калькулятор и страница «О программе».


## Возможности

- Ведение списка заметок (в течение сессии).
- Калькулятор сложения двух чисел с проверкой входных данных.
- Страница «О программе».
- Навигация между страницами через главное окно.

## Структура проекта

- Views/              — окна и страницы WPF
- ViewModels/         — логика представления
- Models/             — сущности (Note, CalculationResult)
- Services/           — сервисы (заметки, вычисления, логирование)
- Infrastructure/
  - Converters/     — конвертеры для привязок
  - Extensions/     — методы-расширения
- App.xaml            — точка входа приложения

## Запуск

1. Открыть решение MyNotesApp.slnx в Visual Studio 2022.
2. Убедиться, что установлен .NET 8.0 SDK.
3. Нажать F5 или «Пуск».
