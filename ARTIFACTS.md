## 3. Протоколы взаимодействия

### Протокол INotesService
Участники: ViewModels → Services
Назначение: предоставление доступа к заметкам.
Интерфейс:
    IReadOnlyList<Note> GetAll();
    void Add(Note note);
Формат данных: объекты C# (класс Note).
Соглашения: имена методов — глагол + существительное.

### Протокол ICalculatorService
Участники: ViewModels → Services
Назначение: выполнение математических операций.
Интерфейс:
  CalculationResult Add(CalculationResult model);
Формат данных: объект CalculationResult.
Соглашения: при некорректных данных выбрасывается исключение ArgumentException.

### Протокол ILoggerService
Участники: Services → внешний файл
Назначение: запись логов действий пользователя.
Интерфейс:
  void Log(string message);
Формат данных: строка вида [yyyy-MM-dd HH:mm:ss] сообщение, дописывается в log.txt.
Соглашения: одна запись на действие; ошибки записи подавляются через try/catch.

### Протокол навигации (Views → Views)
Участники: MainWindow → страницы
Назначение: переход между страницами.
Интерфейс: Frame.Navigate(Page).
Формат данных: объекты Page (NotesPage, CalcPage, AboutPage).
Соглашения: каждая страница — отдельный класс в модуле Views.

### Протокол App (точка входа)
Участники: App → Views
Назначение: запуск стартового окна приложения.
Интерфейс: StartupUri="Views/MainWindow.xaml".
Формат данных: путь к XAML-файлу.
Соглашения: точка входа задаётся в App.xaml.

## 4. Соглашения об именовании и версионировании

### Именование
Классы и интерфейсы — PascalCase (NotesService, INotesService).
Методы и свойства — PascalCase (AddNote, Calculate).
Приватные поля — _camelCase (_notes, _calcService).
Пространства имён — по структуре каталогов (MyNotesApp.Views).
Файлы — совпадают с именем класса (Note.cs, NotesViewModel.cs).
Ветки Git — main.
Сообщения коммитов — Conventional Commits (docs: add ARTIFACTS.md).

### Версионирование
Схема SemVer: MAJOR.MINOR.PATCH.
Версия проекта: 1.0.0.
Теги Git: v1.0.0.
